# 🎬 IMDb Top 250 Movies Analysis

## 📌 Project Overview

An end-to-end Data Analysis project focused on exploring IMDb's Top 250 Movies dataset using Microsoft Power BI.

The project aims to uncover insights into movie ratings, popularity, voting patterns, and historical trends across different decades through data collection, cleaning, transformation, and interactive visualization.

## 🛠️ Tools & Technologies

- **AI-Assisted Web Scraping:** Data collection from the web.
- **Microsoft Power Query:** Data cleaning and transformation.
- **DAX:** Developing analytical measures and calculations.
- **Power BI:** Data modeling, analysis, and interactive dashboard development.

## 🔄 Project Workflow

### 1. Data Collection & Web Scraping
Collected data about IMDb's Top 250 movies using an AI-assisted web scraping tool, extracting relevant movie information and exporting the results into a CSV dataset.

### 2. Data Cleaning & Transformation
Imported the collected dataset into Power Query to clean, transform, and prepare the data for analysis, ensuring consistency and usability.

### 3. Data Modeling & DAX
Prepared the data model and developed DAX measures to calculate key performance indicators and support deeper analysis of movie ratings, votes, and runtime.

### 4. Data Visualization & Dashboard Development
Designed an interactive Power BI dashboard featuring multiple visualizations to explore the dataset and highlight important trends and relationships.

## 📊 Dashboard Highlights

The dashboard includes:

**Key Performance Indicators (KPIs)**
- Total Votes: 196M
- Total Movies: 250
- Average Rating: 8.31
- Average Runtime: 133 minutes

**Average Rating by Decade**
- Compares average movie ratings across different decades.
- Highlights rating patterns and consistency over time.

**Movie Ratings & Voting Analysis**
- Uses a scatter plot to explore the relationship between movie ratings and voting activity.
- Bubble size represents total votes, adding another dimension to the analysis.

**Movies Distribution by Decade**
- Examines how the 250 movies are distributed across different decades.
- Identifies the decades with the highest representation in the IMDb Top 250 list.

## 🔍 Key Insights

- The dataset contains 250 movies with approximately 196 million total votes.
- The overall average movie rating is 8.31.
- The average movie runtime is approximately 133 minutes.
- Movies released during the 2000s have the highest representation in the Top 250 list, with 48 movies.
- The 2010s follow with 44 movies.
- Average ratings remain relatively consistent across decades, ranging from 8.1 to 8.4.
